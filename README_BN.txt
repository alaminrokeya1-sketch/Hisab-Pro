ব্যবহার:
1. ZIP extract করে সব ফাইল একই ফোল্ডারে রাখুন।
2. GitHub Pages বা Netlify-তে ফোল্ডারের কনটেন্ট publish করুন (ZIP-টি সরাসরি deploy-ও করা যায়)।
3. সাইটটি HTTPS-এ খুলুন।
4. Android Chrome-এর মেনু থেকে "Install app" / "Add to Home screen" নির্বাচন করুন।
5. প্রথমবার অনলাইনে অ্যাপ খুলে পেজ লোড হতে দিন; এরপর সার্ভিস ওয়ার্কার ফাইল ক্যাশ করলে অফলাইনে চলবে।

ডেটা ও সীমাবদ্ধতা:
- খাতা/লেনদেন ব্রাউজারের localStorage-এ এই ডিভাইসেই থাকে।
- JSON ব্যাকআপ নিয়মিত ডাউনলোড করে অন্যত্র রাখুন; অন্য ফোন/ব্রাউজারে নিজে থেকে ডেটা যাবে না।
- রিস্টোর করলে বর্তমান ডেটা প্রতিস্থাপিত হবে।
- WhatsApp/SMS পাঠাতে সংশ্লিষ্ট অ্যাপ/ফোনের SMS অ্যাপ খোলে; SMS পাঠানো ব্যবহারকারীকে নিশ্চিত করতে হয়।
- এটি ক্লাউড সিঙ্ক/অ্যাকাউন্ট লগইন/একাধিক কর্মচারীর যৌথ ডেটাবেস সরবরাহ করে না।
- PWA install ও service worker localhost বা HTTPS-এ প্রয়োজন।
